# 🃏 Secret Pull - ระบบร้านสุ่มและจำหน่ายการ์ดสะสมออนไลน์

แอพพลิเคชันมือถือสำหรับร้านขายการ์ดและกล่องสุ่ม พัฒนาด้วย **React Native (Snack Expo)** เชื่อมต่อฐานข้อมูล **Supabase**

---

## 🚀 ฟังก์ชันการทำงานทั้งหมด

### 1. ระบบลูกค้า (Customer)
1. **สมัครสมาชิก (Sign Up):** ลงทะเบียนด้วยชื่อ, อีเมล และรหัสผ่าน พร้อมสร้างโปรไฟล์อัตโนมัติ
2. **เข้าสู่ระบบ (Sign In):** เข้าใช้งานอย่างปลอดภัยด้วยระบบ Auth ของ Supabase
3. **ดูสินค้า / เพิ่ม-ลด-ลบ สินค้าในตะกร้า:** 
   - แสดงรายการการ์ดและกล่องสุ่มพร้อมราคาและสถานะสต็อก
   - เพิ่มสินค้าลงตะกร้า ปรับลดจำนวน หรือลบรายการที่ไม่ต้องการได้
4. **ค้นหาสินค้า:** ค้นหาตามชื่อสินค้า และกดเลือกดูตามหมวดหมู่ได้แบบเรียลไทม์
5. **สั่งซื้อสินค้า:** รวมยอดราคาอัตโนมัติ บันทึกคำสั่งซื้อลงฐานข้อมูล และตัดสต็อกสินค้าทันที
6. **ชำระเงินผ่านระบบ:** หน้าจอจำลองการสแกนจ่ายเงินผ่าน PromptPay QR และบันทึกสถานะชำระเงิน

### 2. ระบบพนักงาน (Staff)
1. **เข้าสู่ระบบพนักงาน:** ตรวจจับบทบาท (`role: 'staff'`) อัตโนมัติเมื่อเข้าสู่ระบบ
2. **จัดการหมวดหมู่สินค้า:** เพิ่ม, แก้ไข และลบหมวดหมู่สินค้า
3. **จัดการสินค้าในร้าน:** เพิ่มสินค้าใหม่, แก้ไขข้อมูล/ราคา/สต็อก/รูปภาพ, และลบสินค้า
4. **ปรับสถานะการชำระเงิน:** ดูรายการคำสั่งซื้อของลูกค้าทั้งหมด และปรับสถานะ (ชำระแล้ว / รอดำเนินการ / ยกเลิก)
5. **ดูยอดขายสินค้า:** แสดงยอดขายสะสมรวมทั้งหมด
6. **รายงานยอดขายวันและเดือน:** สรุปยอดขายประจำวัน (Today) และยอดขายสะสมประจำเดือน (This Month)
7. **รายงานจำนวนลูกค้าทั้งหมด:** นับจำนวนบัญชีผู้ใช้ที่เป็นลูกค้าในระบบ

## 🛠️ ขั้นตอนการติดตั้งและรันบน Snack Expo

1. **เตรียมฐานข้อมูล Supabase:**
   - เข้า [supabase.com](https://supabase.com) แล้วสร้างโปรเจกต์ใหม่
   - ไปที่เมนู **SQL Editor** คัดลอกโค้ดจากไฟล์ `schema.sql` ไปวางแล้วกด **Run**
   - ไปที่ **Project Settings** > **API** เพื่อคัดลอก **Project URL** และ **anon public key**

2. **เปิดโปรเจกต์บน Snack Expo:**
   - เข้าสู่เว็บไซต์ [snack.expo.dev](https://snack.expo.dev)
   - คัดลอกโค้ดจากไฟล์ `App.js` ไปวางในโปรเจกต์
   - แก้ไขตัวแปรบรรทัดบนสุด:
     ```javascript
     const SUPABASE_URL = 'https://your-project.supabase.co';
     const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
     ```
   - เพิ่ม Dependencies 3 ตัวในแถบซ้าย:
     - `@supabase/supabase-js`
     - `@react-native-async-storage/async-storage`
     - `@expo/vector-icons`

3. **การแต่งตั้งบทบาทพนักงาน (Staff Role):**
   - ให้สมัครสมาชิกบัญชีผ่านหน้าแอพก่อน 1 บัญชี
   - เข้าไปที่ตาราง `profiles` ใน Supabase
   - ดับเบิลคลิกแก้ค่าคอลัมน์ `role` ของบัญชีนั้นจาก `'customer'` เป็น `'staff'`
   - เมื่อเข้าสู่ระบบใหม่อีกครั้ง แถบเมนูพนักงาน (จัดการสินค้า, หมวดหมู่, ออเดอร์, รายงาน) จะปรากฏขึ้นทันที
